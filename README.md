# CloudNova Linux Administration

## Overview

CloudNova Linux Administration is a hands-on project that simulates the daily responsibilities of a Junior Linux Administrator and Cloud Support Engineer in a professional IT environment.

The project is built around realistic operational tickets rather than isolated Linux exercises. Each ticket represents a task that could be assigned in a real company, including server provisioning, user management, security hardening, troubleshooting, service management, backups, and system monitoring.

## Objectives

- Build practical Linux administration skills.
- Simulate real-world IT operations.
- Document every task using professional engineering practices.
- Develop a portfolio demonstrating Linux skills for cloud computing roles.

## Environment

- VMware Workstation
- Ubuntu Server LTS
- Git & GitHub
- Visual Studio Code

## Repository Structure

